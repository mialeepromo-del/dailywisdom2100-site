# Daily Wisdom Deals

A free static affiliate-deal website for @dailywisdom2100.

## Files
- `index.html` — site structure
- `styles.css` — visual design
- `script.js` — deal data, filters, search, and buttons

## Add or edit a deal
Open `script.js` and edit the `deals` array.

Replace:
```js
affiliateLink: "#affiliate-link-placeholder"
```
with your real affiliate URL later.

To activate real links, replace the deal button logic or change the button to an anchor element using `deal.affiliateLink`.

## Free hosting
Upload these files to GitHub and connect the repository to Cloudflare Pages or GitHub Pages.
